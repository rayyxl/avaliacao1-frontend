O que é o Sistema Solar?

É o conjunto formado pelo Sol e pelos corpos que permanecem ligados à sua gravidade: planetas, luas, asteroides e cometas. A UAI reconhece oito planetas no Sistema Solar.

Este guia reúne fatos para uma primeira exploração. Na página Planetas em números, compare tamanhos e depois use o formulário de planejamento para organizar uma sessão de observação.
